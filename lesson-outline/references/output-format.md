# 上课流程 JSON 格式规范

## 顶层结构

```json
{
  "小标题A": {
    "教学目标": "可选，一句话",
    "流程": [ { "流程": "...", "讲课内容": "...", "知识点": [ ... ] } ]
  },
  "小标题B": { ... }
}
```

- 顶层键 = 课本**小标题**，与教材原文一致。
- 每个小标题一个对象，含可选 `教学目标` 和必有的 `流程` 数组。

## 流程项字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `流程` | 是 | `流程一：具体主题`，主题明确（如「圆的定义」），不用笼统「引入」「小结」 |
| `讲课内容` | 是 | 完整讲课叙述，可独立阅读，不写成一句话要点 |
| `知识点` | 否 | 对象数组；无课本原文可附则**省略该字段** |

## 知识点项

```json
{ "类型": "定义", "内容": "圆：在一个平面内，……" }
```

| 类型 | 用途 |
|------|------|
| `定义` | 概念是什么 |
| `原理` | 推导、证明思路、推理依据 |
| `定理` | 可引用结论（含推论） |
| `性质` | 由定义/定理推出的常用结论 |
| `公式` | 可代入计算的式子 |

`内容`：贴近课本原文；**不得**含指图用语。

## 禁止出现在 JSON 中

- `如图…`、`图24.1-x`、`如图所示`、`结合图…`、`教材图…所示`
- 流程名或内容含：例1、例2、习题、练习、应用题、求证…
- `section`、`source_images`、`confidence`、`note`、`方法`、`例题`
- 空数组 `知识点: []`

## 流程设计原则

1. 按**上课顺序**拆步，一步一个讲授主题。
2. 只含**新知**（定义、定理、性质、推导），不含例题讲评。
3. 每一步的 `知识点` 只列**本步**用到的课本表述。
4. 文字须能**脱离图片**单独读懂。

## 完整示例片段

```json
{
  "垂直于弦的直径": {
    "教学目标": "掌握垂径定理及其推论，理解圆的轴对称性",
    "流程": [
      {
        "流程": "流程一：圆的轴对称性",
        "讲课内容": "圆是轴对称图形，任何一条直径所在的直线都是圆的对称轴。可沿任意直径对折，使直径两旁部分完全重合来直观说明。",
        "知识点": [
          { "类型": "性质", "内容": "圆是轴对称图形，任何一条直径所在的直线都是圆的对称轴" }
        ]
      },
      {
        "流程": "流程二：垂径定理",
        "讲课内容": "垂直于弦的直径平分这条弦，并且平分弦所对的两条弧。设直径CD垂直弦AA'于M，连接OA、OA'，由OA=OA'及三线合一可得AM=A'M，弧AC=弧A'C、弧AD=弧A'D。",
        "知识点": [
          { "类型": "定理", "内容": "垂直于弦的直径平分弦，并且平分弦所对的两条弧" }
        ]
      },
      {
        "流程": "流程三：垂径定理的推论",
        "讲课内容": "平分弦（不是直径）的直径垂直于弦，并且平分弦所对的两条弧。强调前提是被平分的弦不是直径。",
        "知识点": [
          { "类型": "定理", "内容": "平分弦（不是直径）的直径垂直于弦，并且平分弦所对的两条弧" }
        ]
      }
    ]
  }
}
```
