# 课本图片 → 上课流程 JSON

把用户发来的初中数学课本图片，整理成「按小标题拆分、按上课顺序排列」的教学大纲 JSON。
本 skill **完全自包含**：只靠 Agent 读图 + 本文件的规则即可走完全流程，无需任何项目文件或命令行工具。

## 适用场景

- 用户在对话框**直接发课本照片/截图**（通常同一节 1~9 张，按页码顺序）
- 用户说「提取课本」「整理上课大纲」「生成知识点 JSON」等
- 显式 `@lesson-outline`

## 全流程（对话内完成）

### 步骤 1 · 接收输入
- 把用户发来的图片按**发送顺序**视作同一节的连续页。
- 章节名：用户给了就用；没给则从图片标题推断（如「24.1.1 圆」）；实在判断不了，**只问这一句**章节名，不要追问其他。

### 步骤 2 · 阶段1 理解（脑内完成，不输出中间笔记，除非用户要）
- 通读所有图，识别本节的各个**小标题**（如「圆的基本概念」「垂直于弦的直径」「弧、弦、圆心角」）。
- 为每个小标题，按**上课顺序**拆成「流程一、流程二…」，每一步对应一个**具体讲授主题**（如「圆的定义」「垂径定理」），不要用「引入/小结」这种空泛词。
- 每一步：写**完整讲课内容**（能脱离图片独立读懂），并收集本步用到的**课本原文知识点**。

### 步骤 3 · 阶段2 结构化
- 按下方格式输出**合法 JSON**。

### 步骤 4 · 交付
- **先在回复中给出完整 JSON**（这是主交付物，方便用户直接复制）。

### 步骤 5 · 存盘（可选，按需）
- 仅当用户**明确要求保存**时才写文件，路径优先级：
  1. 用户**指定的完整路径** → 直接写。
  2. 用户只说「保存」未给路径 → 写到 `%USERPROFILE%\Documents\lesson-outline-output\<章节名>_<UTC时间戳>.json`。
  3. 当前工作区明显属于本任务（含 `output/json/`）→ 也可写到该目录。
- 时间戳格式：`YYYYMMDDTHHMMSSZ`（UTC），例：`24.1.1圆_20260603T071811Z.json`。
- **不要**把路径写死成某台机器的某个项目目录。

### 步骤 6 · 保存前自检
- [ ] 顶层键都是课本**小标题**
- [ ] 每个流程项都有 `流程` + `讲课内容`
- [ ] `知识点` 每项带合法 `类型`（定义/原理/定理/性质/公式）
- [ ] 没有「如图…」「图24.1-x」「如图所示」「结合图…」等指图用语
- [ ] 没有例题/习题/练习/例1例2 等流程
- [ ] 没有空数组 `知识点: []`，没有 `section`/`source_images`

## 输出 JSON 格式（必守）

顶层键 = 课本**小标题**。完整细则见 [references/output-format.md](references/output-format.md)。

```json
{
  "小标题": {
    "教学目标": "可选，一句话",
    "流程": [
      {
        "流程": "流程一：圆的定义",
        "讲课内容": "在一个平面内，线段OA绕它固定的一个端点O旋转一周，另一个端点A所形成的图形，叫做圆。让学生理解圆是到定点O距离等于定长OA的动点轨迹。",
        "知识点": [
          { "类型": "定义", "内容": "圆：在一个平面内，线段OA绕它固定的一个端点O旋转一周，另一个端点A所形成的图形" }
        ]
      },
      {
        "流程": "流程二：圆心、半径",
        "讲课内容": "固定的端点O叫做圆心；线段OA叫做这个圆的半径。强调半径是从圆心到圆上任意一点的线段，长度都相等。",
        "知识点": [
          { "类型": "定义", "内容": "圆心：固定的端点O叫做圆心" },
          { "类型": "定义", "内容": "半径：线段OA叫做半径" }
        ]
      }
    ]
  }
}
```

### 必须

- `流程`：写作 `流程N：具体主题`，主题明确。
- `讲课内容`：完整讲课叙述，不是一句话要点概括。
- `知识点[].类型` ∈ `定义 | 原理 | 定理 | 性质 | 公式`；`内容` 贴近课本原文。
- 无课本原文可附时，**省略** `知识点` 字段（不要给空数组）。

### 禁止

- 例题 / 习题 / 练习 / 例1例2 / 应用题讲评 等流程（只保留新知讲授）。
- `如图…`、`图24.1-x`、`如图所示`、`结合图…`、`教材图…所示`（JSON 须能脱离图片阅读）。
- 顶层出现 `section`、`source_images`、`confidence`、`note`、`方法`、`例题`，或旧版平铺 `定义/定理` 结构。
- 空数组 `知识点: []`。

## 备注

- 本 skill 不调用 `extract.py`、不读 `.env`、不连小米/OpenAI 等 API；读图与归纳全部由 Agent 完成。
- 改格式规则时，同步更新 `references/output-format.md`。
