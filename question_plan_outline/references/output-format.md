# 互动解题教案 JSON 格式规范

## 顶层结构

```json
{
  "题目": "本题核心任务",
  "步骤一": {
    "问题": "...",
    "答案": "...",
    "错误提示": "...",
    "历史记录": "...",
    "动效描述": "..."
  }
}
```

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `题目` | string | 是 | 用一句话概括本题目标 |
| `步骤一/二/...` | object | 是 | 按解题顺序排列的互动步骤 |
| `问题` | string | 是 | 面向学生的提问，可用填空 |
| `答案` | string | 是 | 标准答案；多空用分号分隔 |
| `错误提示` | string | 是 | 至少两级提示，推荐三次错误提示 |
| `历史记录` | string | 是 | 累积到本步的关键结论 |
| `动效描述` | string | 是 | 图形或公式动效；无则写「无」 |

## 步骤键名

必须使用中文数字：

- `步骤一`
- `步骤二`
- `步骤三`
- `步骤四`
- `步骤五`
- `步骤六`
- `步骤七`
- `步骤八`
- `步骤九`
- `步骤十`

超过十步时继续使用 `步骤十一`、`步骤十二`。

## 问题设计

- 计算类：问“请计算……是多少？”
- 构造类：问“应在什么位置取点？满足什么条件？”
- 证明类：问“需要证明哪两个三角形相似？依据是什么？”
- 转化类：问“可以把原式转化成哪一个线段和？”
- 最值类：问“什么时候取到最小值？最小值是多少？”

## 答案设计

- 保留关键数学式和结论。
- 多个答案用分号分隔，例如：`D(2,0);CD=√13`。
- 不写长篇解释，解释放进错误提示或历史记录。

## 禁止

- 不要输出输入格式字段：`id`、`outline`、`keyKnowledge`。
- 不要输出 `step`、`title`、`content`。
- 不要输出 `relatedSteps`。
- 不要漏掉最终答案。
