# 上课流程 JSON → 互动教案 JSON

把 **lesson-outline** 产出的大纲 JSON，转成可驱动互动课堂的**分步教案 JSON**。
每个顶层小标题（如「圆」「垂直于弦的直径」）**单独一个 JSON 文件**。

## 输入 / 输出

| | 说明 |
|---|---|
| **输入** | 大纲 JSON：顶层键为小标题，每项含 `教学目标`（可选）+ `流程[]`（`流程`/`讲课内容`/`知识点`） |
| **输出** | 每个小标题 → **一个**教案 JSON 文件 |
| **命名** | `<小标题>.json`，非法文件名字符替换为 `_` |

## 参考结构（必守）

细则与燕尾模型示例见 [references/output-format.md](references/output-format.md)、[references/example-yanwei.json](references/example-yanwei.json)。

```json
{
  "题目": "本单元引导题或学习主题（一句话，可含学习目标）",
  "步骤一": {
    "问题": "向学生提出的互动问题（可含填空 ______）",
    "答案": "标准答案；多空用分号分隔，如 ABG;ACG",
    "错误提示": "第一次错误：……；第二次错误：……；第三次错误：直接显示正确答案",
    "历史记录": "到本步为止已建立的知识摘要（第一步可简短或留空）",
    "动效描述": "本步正确后屏幕/图形动画说明；无则写「无」"
  },
  "步骤二": { ... }
}
```

- 步骤键名：**步骤一、步骤二、步骤三…**（中文数字，不用 step1 / 步骤1）。
- 每一步对应大纲里**一个流程**，顺序与大纲 `流程[]` 一致；不要把多个流程合并成一步。

## 转换规则

### 题目
- 由该单元的 `教学目标` + 第一个流程主题提炼成**一句引导题**或**学习主题**。
- 概念课可写成：「请说出圆的定义，并指出圆心、半径分别是什么？」
- 不必照搬课本例题。

### 问题
- 把 `讲课内容` + `知识点` 改写成**学生可回答的互动问句**。
- 优先：填空（______）、判断、指认（「下列哪个是直径？」）、简短复述。
- 概念定义类：「……叫做什么？」「……记作什么符号？」
- 定理类：「垂径定理的内容是什么？」或补全定理表述。
- **禁止**依赖「如图…」；无图也能作答。

### 答案
- 来自 `知识点[].内容`，精简为**可判分的标准答案**。
- 多空：`答案1;答案2`（参考燕尾模型用分号分隔）。

### 错误提示
- **至少两级**：第一次给方向性话术；第二次给更具体提示或直接揭示关键式子；第三次（可选）写「直接显示正确答案」。
- 话术风格参考燕尾模型：「再想想看吧！」「试试把……统一吧！」

### 历史记录
- **累积式**：本步之前各步已确立的结论，用分号或换行连接。
- 步骤一可留空或只写本步结论；步骤 N 应包含步骤 1~N-1 的关键信息 + 本步新结论。

### 动效描述
- 几何概念课：描述图形出现/高亮/填充/标注（如「将圆心 O 标红，半径 OA 用箭头标注」）。
- 纯文字概念、无图形时写 **「无」**。

## 禁止

- 不要把多个小标题合并进一个 JSON。
- 不要出现例题演算流程（例1、赵州桥求半径等），只保留**概念/定理互动**。
- 不要 `如图…`、`图24.1-x`。
- 不要输出大纲里没有的知识。

## 工作流

1. **接收输入**：用户粘贴 JSON、@ 文件，或指定 `output/json/xxx.json` 路径。
2. **枚举顶层键**：每个键 = 一个待生成教案单元。
3. **逐单元转换**：按上方规则生成教案 JSON。
4. **交付**：
   - 在回复中列出将生成的文件清单 + **每个文件的完整 JSON**（或用户只要某几个单元则只输出那些）。
5. **存盘**（用户要求保存时）：
   - 用户指定目录 → 写入 `<小标题>.json`
   - 未指定 → `%USERPROFILE%\Documents\lesson-plan-output\<章节名>\`
   - 若当前工作区有 `output/lesson-plan/` 可写入该目录

## 自检

- [ ] 每个小标题单独一个 JSON
- [ ] 含 `题目` + `步骤一`… 连续编号
- [ ] 每步含：问题、答案、错误提示、历史记录、动效描述
- [ ] 步骤数与大纲 `流程` 条数一致
- [ ] 无指图用语、无例题流程
- [ ] 历史记录逐步累积

## 与 lesson-outline 的关系

- **lesson-outline**：课本图片 → 上课流程大纲 JSON
- **lesson-plan-outline（本 skill）**：大纲 JSON → 互动教案 JSON

可先 `@lesson-outline` 出大纲，再 `@lesson-plan-outline` 出教案；也可直接给已有大纲 JSON。
