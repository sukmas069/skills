# 互动教案 JSON 格式规范

## 单文件结构

一个 JSON 文件 = **一个教学单元**（对应大纲 JSON 的一个顶层小标题）。

```json
{
  "题目": "string",
  "步骤一": {
    "问题": "string",
    "答案": "string",
    "错误提示": "string",
    "历史记录": "string",
    "动效描述": "string"
  },
  "步骤二": { ... }
}
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `题目` | 是 | 本单元学习主题或引导问题，一句话 |
| `问题` | 是 | 本步向学生提出的互动问题，可用 ______ 表示填空 |
| `答案` | 是 | 标准答案；多个空用英文分号 `;` 分隔 |
| `错误提示` | 是 | 分级提示：第一次错误…；第二次错误…；第三次错误：直接显示正确答案 |
| `历史记录` | 是 | 到本步为止已建立的知识（累积）；第一步可简短 |
| `动效描述` | 是 | 答对后的图形/界面动效；无则写「无」 |

## 步骤键名

- 使用 **步骤一、步骤二、步骤三…**（中文数字）
- 顺序与输入大纲的 `流程[]` 一一对应

## 燕尾模型参考（互动课范式）

来源：`AI-56-1.1燕尾模型.pdf` — 几何模型课通过**分步填空 + 面积比推导**推进。

特点：
1. **问题**带空白，让学生填三角形名或数值比
2. **答案**简洁可判分
3. **错误提示**逐级加强（话术 → 公式 → 给答案）
4. **历史记录**每步累加已得出的比例关系
5. **动效描述**答对后给对应三角形填色

概念课（圆、垂径定理等）沿用同一**五步结构**，但问题改为概念识记、定理复述、符号填空，动效改为圆、弦、弧等元素的高亮标注。

完整燕尾示例见 [example-yanwei.json](example-yanwei.json)。

## 从大纲 JSON 映射

| 大纲字段 | 教案字段 |
|----------|----------|
| `教学目标` + 首流程主题 | `题目` |
| `流程[i].流程` + `讲课内容` + `知识点` | `步骤i` 的 `问题` / `答案` |
| 前 i-1 步的知识点摘要 | `步骤i` 的 `历史记录` |
| 几何概念 | `动效描述`（圆心、弧、三角形填色等） |

## 禁止

- 多个小标题合并为一个 JSON
- `如图…`、图号引用
- 例题演算步骤（例1、应用题求半径）
- 缺少五字段的步骤对象

## 文件命名

`<小标题>.json`，例如：

- `圆.json`
- `垂直于弦的直径.json`
- `弧、弦、圆心角.json`

## 输出目录（存盘时）

1. 用户指定路径
2. 默认 `%USERPROFILE%\Documents\lesson-plan-output\<章节名>\`
3. 工作区 `output/lesson-plan/`（若存在）
